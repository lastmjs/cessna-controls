    How to use · Cómo usar

    Look around

    • Drag to look around, scroll or pinch to zoom.
    • Right-drag or two fingers to move sideways.
    • Click any control or instrument to see its name in English and Spanish.
    • Show me moves the control so you can see how it works. The small airplane shows what the flight controls move.
    • Quiz asks you to find parts. Your progress is saved only in this browser.

    Keyboard

    • ← → previous / next part
    • Space show me · L mark learned · F zoom to it
    • / search · Esc close

    Mirar alrededor

    • Arrastre para mirar, use la rueda o pellizque para acercar.
    • Clic derecho o dos dedos para desplazarse.
    • Toque cualquier control o instrumento para ver su nombre en inglés y español.
    • Muéstrame mueve el control para ver cómo funciona. El avioncito muestra qué mueven los controles de vuelo.
    • Prueba le pide encontrar piezas. Su progreso se guarda solo en este navegador.

    Teclado

    • ← → pieza anterior / siguiente
    • Espacio muéstrame · L marcar aprendida · F acercar
    • / buscar · Esc cerrar
